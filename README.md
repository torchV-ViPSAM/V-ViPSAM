# V-ViPSAM : Visual Prompting for Volumetric Medical Image Segmentation Using Segment Anything Model

The official source code of "V-ViPSAM : isual Prompting for Volumetric Medical Image Segmentation Using Segment Anything Model".

## Implementation

A Pytorch implementation of deep-learning-based model.

- Requirements
  - OS : Ubuntu / Windows
  - Python 3.10.18
  - PyTorch 2.5.1

## Dataset

- ~

## Training

- train.py is the implementation code for training the proposed V-ViPSAM model.
- You can run the code through "bash train.sh apis" in terminal.
- All parameter settings we used are written in ./config/train_config_apis.json file.

## Evaluation

- test.py is the implementation code of inference for medical image segmentation.
- You can run the code by running "bash test.sh apis" in terminal.
